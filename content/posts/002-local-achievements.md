站点里藏了一套成就，十五项，其中三项在解锁前不显示名称。没有账号、没有后端，全部靠 localStorage。整套东西的代码不到一百行。

## 状态集中，一处落盘

一个 Set 存已解锁的编号，任何变更后整体序列化一次。读写都套 try/catch：隐私模式下 localStorage 会直接抛错，这时降级为会话内记忆，功能照常，只是关掉页面就忘。

```js
const KEY = 'rhine.ach';
const read = () => {
  try { return new Set(JSON.parse(localStorage.getItem(KEY) || '[]')); }
  catch { return new Set(); }
};
function unlock(id) {
  const got = read();
  if (got.has(id)) return;
  got.add(id);
  localStorage.setItem(KEY, JSON.stringify([...got]));
  renderCount();   // 侧栏的 3 / 15
  announce(id);    // 一条提示，两秒后擦掉
}
```

## 五个触发面

- 路由：首次到访、打开任意一篇、读完全部七篇
- 滚动：单篇读到 80%
- 时间：深夜（00:00–05:00）与清晨（05:00–07:00）访问
- 输入：快捷键、连点字标、Konami 序列
- 隐藏：找到页脚的 No.000

跨页面记录用同样的键。比如「打开文章」时把编号和时间写进去，下一次任意页面加载时读出来，就知道上一篇有没有停留超过五秒——「匆匆一瞥」这项成就就是这么判定的。

## 通知用现成的提示条

解锁时屏幕下方擦入一条深色提示：编号、名称，一句话说明。两秒后向右擦掉。不弹窗、不遮内容、不打断阅读。

:::note 注意
成就不设「重新锁定」。任何回收已获得成就的设计，都是在惩罚回头客。
:::

## 文案比代码难写

十五项成就的名字都控制在四个字以内，说明只有一句话，不解释怎么拿。写得太直白就没有发现的乐趣，写得太玄又像猜谜。最后的标准是：拿到的时候能笑一下，就够了。

三项隐藏成就只在解锁前显示线索：页脚的编号、首页的字标、一段古老的按键序列。线索放在成就列表里，而不是到处写提示——找得到的人自然会去找。

> 游戏化不是为了留住人，是让独处的读者被看见一下。
